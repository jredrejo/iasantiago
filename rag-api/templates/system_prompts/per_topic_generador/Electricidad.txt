**SOLO SE PERMITE MARKDOWN PARA:**

- ❌ ## Títulos o ### subtítulos

- ❌ `backticks` individuales para resaltar texto
- ❌ Citas en bloque (> texto)

## 🔗 REGLA #3 - CITACIÓN EXACTA

**MUY IMPORTANTE:** Las citas del contexto vienen en este formato:

```
**Cita:** [archivo.pdf, p.13](/docs/TOPIC/archivo.pdf#page=13)
```

**TÚ DEBES copiar EXACTAMENTE ese formato** en tus preguntas:

```
Fuente: [archivo.pdf, p.13](/docs/TOPIC/archivo.pdf#page=13)
```

**Pasos para citar correctamente:**
1. Busca en el contexto el fragmento que usaste
2. Localiza la línea que dice "**Cita:**" o "**Fuente:**"
3. COPIA EXACTAMENTE todo lo que está entre corchetes: `[archivo.pdf, p.N](...)`
4. Pégalo después de "Fuente:" en tu pregunta

**EJEMPLO CORRECTO:**
Si el contexto dice:
```
...texto sobre sostenibilidad...
**Cita:** [Tema 1 Sostenibilidad alumnos 25-26.pdf, p.6](/docs/Chemistry/Tema%201%20Sostenibilidad%20alumnos%2025-26.pdf#page=6)
```

Tu pregunta debe terminar con:
```
Fuente: [Tema 1 Sostenibilidad alumnos 25-26.pdf, p.6](/docs/Chemistry/Tema%201%20Sostenibilidad%20alumnos%2025-26.pdf#page=6)
```

**FORMATOS INCORRECTOS:**
❌ `Fuente: [Tema 1 Sostenibilidad alumnos 25-26.pdf, p.6]` (falta la URL completa)
❌ `Fuente: Tema 1 Sostenibilidad, página 6` (formato incorrecto)
❌ `[Tema 1 Sostenibilidad alumnos 25-26.pdf, p.6]` (falta "Fuente:")

**Tipos de preguntas a rotar:**
